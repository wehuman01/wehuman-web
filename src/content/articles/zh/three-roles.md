一个常见的朋友圈：有人显卡闲着，有人订阅用不满，还有人什么都缺。最直接的共享办法是把 API key 直接发过去——但谁都犹豫：key 给出去等于把整串钥匙交了出去，用超了、泄露了、账号被封了，后果全是自己的。

aweshare 把这件事拆成三个角色：出算力的、用算力的、守门的。这篇文章不讲安装、不讲命令，只讲清楚每个角色做什么、边界在哪，以及背后的设计哲学。

## 生产者：有算力的人

你有一张闲着的显卡，或是一个用不满的订阅——在 aweshare 里，你是生产者。你要做的只有一件事：把想共享的模型「上架」。你的电脑上跑一个小程序，它主动连到中转站，把你的模型登记进目录，比如「老王/qwen 大模型」。之后朋友按这个名字来调用。

这个角色的体验由三条边界决定：

- **钥匙不出门。** 你的 API key、订阅凭证，从始至终留在你自己的电脑里。别人调用时，请求被转回你的电脑，由你电脑上的程序拿着钥匙去敲上游的门。别人从头到尾看不到钥匙——连中转站也看不到。
- **你的电脑不用开门营业。** 那条连接是你主动往外打的，像打电话，不像开店铺。不需要公网 IP，不需要端口映射，不用改防火墙——家里的笔记本、公司内网的台式机，都能当生产者。
- **护栏你自己定。** 同时接待几个人、一天最多用多少、总共放行多少，都是你上架时写清楚的。电脑一关，或你把模型下架，共享立刻停止；想回来，随时重新上架。

一句话：生产者共享的是**能力**，不是**钥匙**。别人能用你的模型，碰不到你的账号。

## 消费者：要算力的人

你缺一张好显卡，或是不想为一个偶尔才用的模型再开一份订阅——在 aweshare 里，你是消费者。

这个角色的体验刻意做得无聊：拿到一个令牌（一串字符）和一个地址，填进你本来就在用的工具——Claude Code、Codex，或任何支持自定义接口的客户端——模型一栏填目录里的名字，就结束了。没有新软件要装，没有新协议要学。共享出来的模型，用起来和任何一家 API 供应商没有区别。

你看不到的东西和你能用的东西一样值得说：你看不到任何人的钥匙，看不到提供者的真实地址，也看不到别人的流量。你能看到的只有目录——谁共享了什么、在不在线、额度还剩多少。

## hub 运营者：守门的人

中转站（hub）需要有人运营。这个人不做复杂的事：

- **发邀请。** 进门凭邀请码，一人一码，用一次作废。没有码，谁都进不来。
- **看电表。** 谁用了多少、什么时候用的，账目一清二楚，公平与否有据可查。
- **踩刹车。** 有人滥用？限流，或者挂起——都是可逆的操作，随时能收回，也不会删掉任何历史。

还有一条必须诚实交代的边界：**所有经过中转站的流量，技术上运营者是看得见的。** 这不是被藏起来的缺陷，而是被写明白的架构事实。应对方式也直接——中转站的代码完全开源，谁都可以自己搭一个：你不信任别人守的门，就自己守一扇。项目作者自己运营着一个社区版（`https://aweshare.wehuman.top`），不信任它的读者随时可以另起炉灶。

## 设计哲学

三个角色背后，是几条贯穿 aweshare 的原则。

**共享能力，不共享钥匙。** 这是最核心的一条。钥匙给出去就是全给，收不回来；aweshare 把它换成按次、按量、随时可收回的能力。生产者的损失上限是「别人用掉的额度」，而不是「整个账号」。

**连接永远是主动打出去的。** 生产者的电脑只往外打电话，中转站从不回拨。这条设计让「共享」不再要求「有一台暴露在公网的服务器」——家用宽带、公司内网都能出算力，这是多数共享方案做不到的。

**准入即权限，护栏即管理。** 权限模型只有一句话：进得来，就能用目录里所有的东西。没有授权树，没有角色配置页。公平不靠审批靠限额——每个模型、每个人的用量上限都写在门口，超了会被明确拒绝，理由说清楚，不含糊。

**诚实的边界比漂亮的承诺值钱。** 中转站看得见流量，aweshare 不假装它是加密通道，而是把边界写明、把代码开源、把自建权交给你。协议不匹配会得到明确的报错，而不是被悄悄翻译成错误的结果。挂起是可逆的。该说清楚的都写在明处。

**只记账，不留内容。** 每个请求记一行账：谁、用了哪个模型、多少字、多久。内容本身一行不存。账目够算清公平，内容不该被留下。

## 三个角色怎么碰头

最常见的场景是一群朋友：一个人出显卡跑开源模型，一个人把用不满的订阅挂上来，其余的人各拿一个令牌来用。守门的可以是其中任何一个人，也可以直接用社区版 hub。整套东西的安装和日常管理都设计成可以交给 AI 智能体——你说话，它干活；只有启动常驻程序这种事，必须你亲手在自己的终端里做。

整场合作里，没有人在群里传钥匙，除了守门人没有人需要买服务器，每个人的退出成本都接近零：生产者关掉程序，消费者删掉两行配置，仅此而已。
