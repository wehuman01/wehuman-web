大多数"智能"LLM 路由器，聪明得很烧钱。它们要么在你的请求上跑一遍 LLM 分类器来决定去向，要么拿关键词匹配一份人工整理的列表，要么把整个对话历史回放进一个评分函数。

这些方案共享一个隐性成本：分类器在每个请求上烧掉 token——这些 token 你不仅要付钱，而且是额外叠加在请求本身之上的。关键词列表增加延迟，而且会慢慢过时。评分函数需要你的对话历史，这意味着它在读取它本不该读取的东西。

而且它们都在猜。分类器可能两个方向都猜错。错误的路由决策要么是浪费钱，要么是降级质量——无论哪种，你都看不见。

awerouter 从结构路由。请求的形状——它声明了哪些工具、携带的 model id 是什么、有多少 token、智能体刚做了什么——本身就是足够好的路由信号。而读取这个形状是免费的。

## 四个问题，零 token

每个请求都经过一个"首次匹配即命中"的管道。四层，每层问一个问题，每层的回答成本逐层降低：

**flash 能处理这个请求吗？** 如果请求声明了 `web_search` 工具，这里考量的不是难度，而是能力。很多廉价提供商不支持它。路由到能处理的提供商去。

**客户端选了哪个层级？** Claude Code 的 `/model` 选择器已经对任务做了分类：后台工作 versus 深度思考。当客户端把 `"flash"` 或 `"pro"` 作为 model id 发送时——这是默认的层级标签，可在设置中改名——这是一个指令，而非需要解读的信号。照单路由。

**这个请求有多大？** 和阈值比 token 数。如果请求携带的内容超过限额——或者包含图片——就路由到高性能层。这是唯一衡量难度的一层，而且它的计量工具是一把尺子，不是一个分类器。

**代码刚被改过吗？** 结构看不到*决定*编辑的那一轮——等到有工具调用可读时，决策已经做完了。它能做的是反应：编辑之后的下一轮是审查轮——核对 diff、决定下一个文件。那一轮交给高性能层；廉价层起草，高性能层审查。末尾那一批工具调用是一个诚实的信号，读取它分文不花。

如果没有任何一层触发，默认走低成本层。便宜推定，除非证明要花大钱。

## 路由所需的信号，请求里全有

核心洞见在于：路由器做决策所需的一切，在任何一个字节向上游发送之前，就已经存在于请求体里。

- `tools` 数组告诉你请求需要什么能力。
- `model` 字段告诉你客户端选了哪个层级。
- 消息内容告诉你上下文有多大。
- 末尾那一批工具调用告诉你代码是否刚被改过。

这些都不需要解释，不需要调用模型。路由器读取结构、做出决策、转发请求——一次本地 HTTP 往返即可完成。

## Token 与 Token 并不一样

一个值得注意的细节：这里的 token 数不是简单求和。文件搜索结果——grep 匹配、glob 列表、目录树——是低信息密度的机械数据。它们撑大了请求的体积，但对推理难度几乎毫无贡献。

一个塞了两百个文件路径的上下文是很大，但不算难。如果路由器按原始大小比较，每一次搜索密集的会话都会因为文件列表的体积而被提升层级——为一个长得离谱的 `ls` 输出支付高性能层的价格。

所以搜索结果的 token 在阈值比较前打了折扣。路由器测量的是真正给模型带来压力的那部分上下文。衡量难度，而非体量。而且这些刻度盘并不锁死：搜索结果的折扣比例、长上下文阈值等参数都写在配置里，用户可以根据自己的模型组合和工作负载自行调整。

## 路由器不读取你的对话

这个设计中最不寻常的一条约束是：响应体是不透明的。路由器从不解析、缓冲或检查上游返回的字节——它们从提供商到客户端原样透传。它唯一读取的是状态码，且只为判断一次低成本层故障是否值得交由高性能层营救。这次读取同样分文不花。

这就杜绝了一整类"更智能"的路由器——那些读取输出、判断质量、在反馈循环中调整路由的方案。不读取响应，就没有质量上的 ground truth，也就无法搭建一个真正关心质量的路由器。awerouter 不假装自己能做到。

相反，每一个决策都来自第一个字节返回之前就能测量的事实。零分类成本。诚实本身就是设计。

## 每次决策都有名字

每一个被路由的请求都会获得一个标签：`webSearch`、`background`、`think`、`longContext`、`image`、`toolEdit`、`default`——以及低成本层故障被拯救时的 `→fallback`。

当你查看用量分析，看到 70% 是 `default`、14% 是 `longContext` 时，你看到的不是黑箱的判决书。你看到的是每一个请求触发了哪个问题，每一个都留有记录。

一个靠猜的路由器只能用感觉为自己辩护。一个只测量的路由器只需展示它的工作过程——而它确实做到了。

## 押注，重述

请求的结构，足以告诉你它的成本和难度。读取这个结构是免费的。一个本可以分文不花就做出的决策，路由器绝不该在 token、延迟或风险上额外付费。

四个问题，从确定问到猜测，配上一个廉价的默认值和单向安全门。没有分类器。没有关键词。没有神谕。只有测量，诚实而有界。
